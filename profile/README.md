# FancyBarGuys

Side-project organisation of [**Federico Vita**](https://github.com/fedevita).
Home of **FitFriends** — a mobile app for finding training partners.

> Repositories here are private while the product is in development.

## FitFriends

**Serverless AWS backend**
- 36 Python Lambda functions
- API Gateway, REST + WebSocket
- DynamoDB with single-table design
- Infrastructure as code with AWS SAM
- Dev and prod isolation on AWS Organizations

**Client**
- Flutter, cross-platform

**Delivery**
- GitHub Actions CI/CD with a quality gate at ≥90% test coverage
- Design system and UI/UX documentation maintained alongside the code

`Python` · `AWS Lambda` · `API Gateway` · `DynamoDB` · `SAM` · `Flutter` · `GitHub Actions`
